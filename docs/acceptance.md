# 验收与验证

## 自动验证

最终执行结果见本文件末尾的记录。Flutter 测试使用可注入的假通道，仅验证界面 / 控制器；不能替代原生或实际服务验证。Android instrumentation 在专用 Android 16 模拟器中验证真实 SQLite / Keystore，不使用真实个人账号。

## Android 16 实机验收清单

### 微信和 QQ

- 在接入管理授权通知访问，返回应用，确认显示“监听中”。
- 分别接收单聊、群聊、同一会话连续消息、图片 / 语音通知，检查可见文本与来源。
- 已读后重放同一通知不会恢复本地未读；归档后重放不会返回收件箱。
- 关闭通知来源开关后不再写入新记录；重启应用后开关保留。
- 进程不在前台时收取消息，再打开应用检查记录。
- 清除原通知后打开历史记录，应打开原应用或提示未安装，不假称定位成功。
- 禁止通知详情、撤销权限和系统隐藏敏感通知时，界面如实表现可见内容。

### QQ / 网易 IMAP

- 使用测试邮箱开启 IMAP，以授权码添加账号。
- 正确账号保存并显示同步时间；错误授权码 / 网络断开显示错误，凭据不进入日志。
- 初始未读导入不会改变服务器已读状态；后续新邮件按 UID 去重。
- 本地已读 / 归档后再次同步，不覆盖本地决定。
- 两个同服务商账号的相同 UID 不相互覆盖。
- 连续有超过 200 封新邮件时，后续同步继续获取剩余邮件。
- 更新授权码、移除账号及后台同步并发时，不重新出现已移除账号的记录。
- 系统省电、断网、强行停止与重启后的周期行为需在目标手机上观察。

### 短信

- 首次明确同意后才出现权限请求；拒绝时不读取，界面显示未授权。
- 初次仅导入近 7 天未读短信；已有历史短信不会在第二次同步时意外全部导入。
- 新短信写入系统收件箱后，通过广播 / 周期补偿导入。
- multipart、双 SIM、无发件人、权限中途撤销、默认短信应用写库延迟需要实机验收。
- 本地已读不改变系统短信已读；停用接入不删除历史记录。

### 隐私与界面

- 搜索与来源 / 未读 / 归档筛选能组合使用。
- 重启后已读、归档、账号和接入开关仍保留。
- 账号移除只删除该账号本机数据；取消对话框不删除。
- Gmail 清晰显示待接入，没有授权或收取邮件的成功提示。
- 小屏、大字体、键盘弹出、长消息 / 长邮箱地址及无网络时界面可操作。
- 未授权 / 没有消息时显示真实空状态，生产代码不注入演示记录。
